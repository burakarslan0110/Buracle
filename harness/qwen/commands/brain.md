Open the Buracle memory UI for the user. Arguments: {{args}}

With no argument run `"${BURACLE_HOME:-$HOME/.buracle}/bin/buracle" mem ui --open`; with `review` run `"${BURACLE_HOME:-$HOME/.buracle}/bin/buracle" mem ui --open --page review`. Run it with the shell tool, then say in one line what opened.
